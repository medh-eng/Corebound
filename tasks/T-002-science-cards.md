## Goal
Every machine and resource gets a short "science card": the real science behind it, simplified for players aged 10–25 (GDD §9: "Science cards: one short card per machine").

## Read first
- `AGENTS.md`
- `docs/GDD.md` §8 Power, §9 Elements, machines, research
- `src/data/items.ts` (current item notes, to match tone)

## What to write
One card each (60–100 words) for:
- **Machines:** shelter dome, solar lotus (solar panel), battery, electrolyzer, smelter, auto-drill (mine), refinery, silicon furnace, coal burner, bio-filter, settling pond, Sabatier reactor, liquid drill, fuel processor (biofuel), biofuel power station, windmill, geothermal plant, launch pad, space elevator.
- **Resources:** ice/water, iron ore, silica, carbon, copper, aluminium, titanium, gold, diamond, oil, hydrogen, oxygen, methane, CO2.

Each card: a one-line title, the science in plain words, **one real-world fact** (for example where on Earth it is used), and, where it fits, the simple chemical equation (for example `2H₂O → 2H₂ + O₂`). If a machine pollutes, say honestly how and how it could be cleaner.

## Format
```
## electrolyzer
Title: Splitting water with electricity
Card: ...
Equation: 2H₂O → 2H₂ + O₂
Real world: ...
```
