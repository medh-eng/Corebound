# COREBOUND

**Build. Automate. Survive. Preserve.**

A 2D survival-factory game on small, living round planets. Walk all the way around each world, dig toward its core, and build the machines that keep you alive and carry you onward. Every machine changes the world: skies haze, forests wilt, and giant Guardians wake. You win them over with engineering, never weapons.

Built by Claude from an original idea, for release on the web, itch.io and Steam.
