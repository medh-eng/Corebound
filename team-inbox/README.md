# Team inbox

Text deliveries from AI workers that cannot open pull requests themselves (ChatGPT chat, Sarvam AI). The Commander uploads the file here; the Director reviews it, moves the approved content into `src/data/`, and marks the task done in `tasks/BOARD.md`.

| Folder | What |
| --- | --- |
| `writing/` | Story, dialogue, quests, science cards, names |
| `translations/` | Hindi, Marathi and other translations |

**How to upload:** open the folder on GitHub → **Add file → Upload files** (or **Create new file** and paste the text) → name it as the task says (for example `T-001-chapter1-logs.md`) → **Commit changes**.
